# Ассистент панели: DeepSeek и Gemini

Изменения от 2026-10-04 готовы в исходниках; production пока не обновлён.
Это помощник сотрудников в Aurum Panel, не функция игрового сайта.

## Подключение

ГМ открывает **Настройки → AI-ассистент**, выбирает провайдера и модель,
вставляет его API-ключ и сохраняет. Затем включает помощника.
Ключи DeepSeek и Gemini сохраняются отдельно: переключение не удаляет второй ключ.
Пустое поле не меняет сохранённый ключ; «Удалить ключ» касается выбранного провайдера.
Существующие ключ и модель DeepSeek сохраняются при обновлении.
Автоматического переключения на другого провайдера при ошибке нет.

Для Gemini:

1. Открыть [Google AI Studio](https://aistudio.google.com/) своим Google-аккаунтом.
2. В Projects создать **Aurum Panel AI**. Если Cloud-проект уже есть — выбрать
   **Import projects** и найти его. Импорт — выбор проекта из своего Google Cloud,
   а не загрузка файла с описанием панели.
3. В API keys создать ключ в этом проекте и внести его в настройки панели.
   Не отправлять ключ в чат или GitHub. В Cloud Console по возможности ограничить
   его Gemini API и исходящим IP сервера API, не доменом браузерного сайта.

Проект объединяет ключи, квоты, доступ сотрудников и оплату. Он не содержит
«контекст панели»: подсказки и разрешённые результаты инструментов отправляет наш
API при каждом обращении. [Документация ключей и проектов Google](https://ai.google.dev/gemini-api/docs/api-key).

Для API-клиента с пользователями в Польше/ЕЭЗ по текущим условиям Google нужен
активный Cloud Billing. Подписка Gemini Pro не заменяет API-ключ и биллинг проекта.
Также действуют возрастные ограничения Google: помощник Gemini — для сотрудников
18+, не переносить его автоматически на пользовательский игровой сайт.
[Условия Gemini API](https://ai.google.dev/gemini-api/terms).

## Что добавилось

- Просмотр счетов Core, их ролей, балансов и журнала операций.
- Перевод между выбранными счетами с суммой, валютой и обязательной причиной.
- Чтение и изменение налогов, лимитов, обменов и стартового баланса через
  штатные Core preview/apply. В подтверждении видны поля до/после.
- Whitelist, подробности гильдии и справка по доступным разделам панели.
- Кнопка остановки ответа. Закрытие чата прекращает запрос к модели, но не
  отменяет уже подтверждённую операцию.

Примеры: «Покажи счёт финала colosseum», «Переведи 500 coins из глобальной казны
в финальный фонд colosseum, причина: пополнение», «Покажи лимит переводов».
Изменения выполняются только после подтверждения карточки.
Если прав, Core или нужного плагина нет, инструмент не обходит это через консоль.

## Лимиты

В блоке «Лимиты и бюджет» ГМ задаёт ограничения и нажимает «Сохранить».
По умолчанию: 30 обращений/час и 200 000 токенов/сутки на сотрудника;
32 768 входных и 4096 выходных токенов на шаг модели;
общий бюджет всех сотрудников и обоих провайдеров — **$1/сутки и $10/месяц**.
День и месяц считаются по UTC, час — скользящее окно.

Один вопрос может включать до пяти шагов модели. До обращения резервируется
максимальный расход всех пяти, после ответа неиспользованный резерв освобождается.
Поэтому новый вопрос иногда отклоняется, хотя видимый расход ещё ниже лимита.
При обрыве без данных о расходе один начатый шаг считается по верхней границе.
Это оценка для защиты бюджета, не счёт от провайдера; скидки за кеш/время суток
не учитываются. Старые записи не пересчитываются в доллары задним числом.
Тарифы и список моделей проверены 2026-10-04:
[DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/),
[Gemini](https://ai.google.dev/gemini-api/docs/pricing).

Для экономии панель подбирает инструменты по правам, вопросу и открытому разделу,
загружает справку по запросу, ограничивает результаты и убирает старую переписку
при нехватке контекста. Вход оценивается консервативно по размеру UTF-8, без
отдельной зависимости-токенизатора. Модель не получает весь README или всю базу.
Большое контекстное окно модели не означает, что его надо заполнять.

## Безопасность и неизвестный результат

Ключи зашифрованы в API, браузер получает только признак наличия.
Аргументы проверяет сервер, доступ перепроверяется при исполнении.
Одно подтверждение атомарно переводит карточку в `executing`: повторный клик
не запускает вторую операцию. Денежные операции Core используют стабильный ID.
Изменение правила применяет сохранённый preview с проверкой ревизии, а не новый
preview после клика. Истёкший preview нужно подготовить заново.

Если ответ на подтверждение потерялся, браузер только читает статус карточки —
не повторяет POST. При аварии API статус может остаться `executing`; проверить
аудит/ledger и результат вручную, не просить второй перевод наугад.
Неизвестный исход нельзя объявлять неуспешной операцией без такой проверки.
Ошибка завершения учёта расхода оставляет резерв до расследования: защита не
разблокирует его автоматически. Все эти состояния записаны для следующего агента.

## Выпуск и следующий этап

Нужны **API и web вместе**, не только веб-сборка. После обновления исходников:
`npm ci`, `npm run prisma:generate`, `npm run build`, затем штатный
`prisma migrate deploy` с окружением API и перезапуск API по `deploy/UPDATE.md`.
Новая PostgreSQL-миграция — `20261004150000_ai_providers_and_limits`.
Она добавляет поля расходов и статус `executing`, не меняет ключи или баланс игры.
Core/Companion/JAR обновлять для этого этапа не требуется.
Миграция пока не применялась на живой БД; перед выпуском нужна проверка на staging.

Локальные тесты, сборки и браузерный mock-прогон desktop/mobile выполнены.
Реальные API-запросы к DeepSeek/Gemini и платный smoke не выполнялись.
Нужно проверить настоящий function-call цикл Gemini, отмену, расход и PostgreSQL
конкуренцию после согласованного выпуска. Для оплаты выставить также ограничения
у провайдера: собственный бюджет панели не покрывает использование ключа вне панели.

Далее: ограниченная диагностика логов/файлов с удалением секретов, работа с бэкапами
и расписаниями через штатные сервисы; затем типизированные инструменты NPC/Arena/Slots
и управления гильдиями. Скриншоты, кеширование контекста и автоматические сценарии
в этот этап не входят. Порядок — в `AI-HANDOFF.md` и roadmap.

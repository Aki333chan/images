# Companion-плагин для модуля Minecraft

Модуль Minecraft работает без плагина: игроки, кик, бан, whitelist и команды
идут через RCON. Но у RCON есть предел — он отдаёт только текст. Поэтому
companion-плагин нужен для того, чего в текстовом ответе нет:

| Возможность | Без плагина | С плагином |
| --- | --- | --- |
| Список игроков | ники (разбор ответа `list`) | ники + UUID + пинг |
| Аватары Crafatar | заглушка из двух букв | настоящий скин по UUID |
| Инвентарь игрока | недоступен | сетка предметов, броня, вторая рука |

> Плагин пока **не реализован** — этот документ фиксирует контракт, по которому
> его будет ждать панель. Пока плагин не настроен, вкладка «Инвентарь» показывает
> ссылку на эту страницу, а остальные функции модуля работают.

## Как панель обращается к плагину

Плагин поднимает HTTP-сервер на игровой машине и слушает **только на приватном
адресе** (`10.0.0.2`) — наружу он смотреть не должен. Панель ходит к нему через
уже существующий WireGuard-туннель.

Авторизация — статический токен в заголовке:

```
Authorization: Bearer <token>
```

Адрес и токен задаёт ГМ в панели (право `minecraft.configure`). Они хранятся
зашифрованными (AES-256-GCM) вместе с RCON-кредами и **никогда не возвращаются
в ответах API и не пишутся в аудит-лог** — эндпоинт статуса отдаёт только флаг
«настроено / не настроено».

## Контракт эндпоинтов

### `GET /players`

```json
{
  "players": [
    { "name": "Steve", "uuid": "8667ba71-b85a-4004-af54-457a9734eed7", "ping": 42 }
  ]
}
```

`uuid` и `ping` необязательны: если плагин их не отдаёт, панель покажет прочерк.

### `GET /inventory/{name}`

```json
{
  "items": [
    { "slot": 0, "id": "minecraft:diamond_sword", "count": 1, "displayName": "Меч Стива" },
    { "slot": 9, "id": "minecraft:cobblestone", "count": 64, "displayName": null }
  ],
  "armor": [
    { "slot": 0, "id": "minecraft:diamond_helmet", "count": 1, "displayName": null }
  ],
  "offhand": { "slot": 0, "id": "minecraft:shield", "count": 1, "displayName": null }
}
```

Нумерация слотов — как в Minecraft: `0–8` хотбар, `9–35` основной инвентарь.
Броня — 4 слота, `offhand` — один предмет или `null`.

## Требования к реализации

- Отвечать за разумное время: панель ждёт ответа 4 секунды, дальше считает
  плагин недоступным и мягко деградирует (инвентарь показывает инструкцию,
  список игроков берётся из RCON).
- Возвращать `401`, если токен не совпал.
- Не логировать токен.

## Настройка в панели

1. Установите плагин на игровой сервер и задайте в его конфиге токен.
2. В панели откройте сервер → настройки модуля (доступно роли ГМ).
3. Укажите адрес вида `http://10.0.0.2:8080` и тот же токен.

После этого вкладка «Инвентарь» станет рабочей, а в списке игроков появятся
аватары и пинг.

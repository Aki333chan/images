# Aurum ecosystem roadmap

Этот файл обновляется после каждого законченного этапа. Верхний незавершённый
пункт — следующий в работе.

## Завершено

- [x] Архитектурная граница AurumCore, модулей и Companion.
- [x] Пассивный AurumCore 0.1.0: API, наблюдение Vault, placeholders, MariaDB
  migrations, локализации и полностью отключённые денежные записи.
- [x] Модель глобальной казны отдельно от общей денежной массы.
- [x] Расширяемая оболочка financial policies: налоги, сборы, комиссии,
  кешбэк, субсидии, лимиты, льготы и versioned custom handlers.
- [x] Проектирование гарантированного обмена через holds, TRADE_ESCROW,
  revision confirmations и восстанавливаемую saga/outbox.
- [x] Безопасное пространство команд: `/pay`, а администрирование только через
  `/aurum economy ...` (`/aurum eco ...` как внутренний алиас).
- [x] Ledger engine 0.2.0: атомарный MariaDB executor, блокировки счетов в
  стабильном порядке, idempotency, запрет отрицательного баланса, казна,
  money supply, аудит отказов, outbox и конкурентные тесты. Paper/Vault доступ
  к денежным записям пока намеренно не включён.
- [x] Shadow/migration 0.3.0: неизменяемые снимки Vault, чтение порциями без
  длительной нагрузки одного тика, отчёт расхождений, защищённый повторяемый
  import в неактивный ledger, verify и rollback CSV. Essentials/Vault остаются
  рабочим провайдером и не изменяются.
- [x] Публикационный контракт экосистемы: исходники и каталог панели находятся
  в `Images`, готовые JAR — в `Addons`, а установка панелью идёт только из
  GitHub Releases с отдельными тегами `<name>-v<version>`.
- [x] Active economy 0.4.0: AurumCore — авторитетный MariaDB ledger и
  VaultUnlocked-провайдер; безопасный cutover gate, кэшированные чтения,
  атомарные записи, `/pay`/`/apay`, баланс, казна, give/take/set, права,
  лимиты, причины, локализации и умное tab completion.
- [x] Policy engine 0.5.0: цепочка TAX/FEE/COMMISSION/CASHBACK/SUBSIDY,
  LIMIT и EXEMPTION; расписание и условия, YAML bootstrap/import, управление
  командами, неизменяемые DB revisions и атомарный аудит сумм каждого правила.
- [x] Multi-currency и exchange engine 0.6.1: до 16 валют, одна primary-валюта
  для Vault, native API для остальных, курсы/комиссии/лимиты/расписания/условия,
  ревизии котировок, атомарный обмен и безопасный повтор после истечения котировки.
- [x] Durable holds 0.7.0: резерв полного списания с учётом policy, защита
  доступного баланса от параллельных трат, атомарные capture/release, TTL и
  безопасное восстановление capture после потерянного ответа MariaDB.
- [x] AddonsNPC 1.9.0: магазины, скупщики и торговцы бонусами переведены с прямых
  Vault-записей на holds; добавлен `transactions.yml` и периодическое recovery.
- [x] AurumSlots 1.4.0: денежные ставки переведены на holds и native API;
  выплаты и аварийные возвраты идемпотентны, а физический gold-only режим не требует Core.
- [x] AurumArena 1.5.0: ставки, выплаты, возвраты и чемпионский пул переведены на holds
  и native API. Касса ставок и призовой пул — разные счета. Комиссия стала настраиваемой
  проводкой: в казну сервера или в чемпионский пул, со ставок всегда, с пула по выбору.
  JAR собран; релиз в Addons ещё не выпущен.

## Осталось — в порядке выполнения

1. [x] Перевести AurumGuilds на native API: счёт `GUILD:<id>`, взносы, снятия и роспуск
   с ненулевым балансом (0.4.0). Holds не понадобились — обе стороны операции денежные,
   хватает атомарной `transfer`. Бонусы за счёт казны переводить было нечего: они
   денег не трогают.
2. [x] Усилить предметную часть saga до полноценного claim/quarantine-хранилища.
   Слой доставки реализован в Core 0.8.0 (`AurumClaimApi`, `aurum_claims`, migration 8,
   `/aurum claims`), все потребители AddonsNPC переведены в 2.0.0 — магазины, скупщики и
   гильдейские торговцы. Следующий потребитель — гарантированная торговля.
3. [x] Реализовать гарантированный player trade (Core 0.9.0): машина состояний с
   ревизиями, изъятие предметов в запись, расчёт денег через holds, возврат и выдача
   заявками, команды `/trade` и окно одной сделки — оболочка над тем же сервисом, а не
   второе место, где записаны правила.
4. [ ] Подключить AurumUI: баланс, переводы, сделки, казна и админские формы.
5. [~] Переделать Companion и веб-панель с Vault-summary на AurumCore API.
   Сделано (Core 0.10.0 + Companion 0.6.0): доска богатства одним запросом к ledger
   (`AurumEconomyApi.richest`), баланс и общая картина из Core при `EconomyMode.ACTIVE`
   с откатом на Vault, поле `source` в `/economy`, а в панели — плитки казны и налогов
   вместо суммы по кошелькам. Осталось: оборот, источники/стоки, правила и ledger
   history — то, чему в панели пока нет ни экрана, ни маршрута.
6. [ ] Опционально мигрировать динамические настройки арен, NPC, автоматов и
   связей гильдий. WorldGuard остаётся владельцем самих регионов.
7. [ ] Полный staging-прогон Paper 26.2 + MariaDB + VaultUnlocked, нагрузка,
    сбои БД/рестарты, Spark и финальная инструкция переключения Essentials.

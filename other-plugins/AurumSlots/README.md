# AurumSlots 1.1.2

Исправленная версия плагина слот-машин для Paper/Spigot 26.2.

## Требования

- Java 25 или новее.
- Paper/Spigot 26.2.
- Для `use_vault: true`: Vault либо совместимая реализация API Vault и отдельный плагин экономики.

## Оплата

- `use_vault: true` — ставка списывается с баланса при нажатии кнопки, выигрыш зачисляется на баланс.
- `use_vault: false` — ставка вносится кликом по воронке с золотом в основной руке, запуск производится кнопкой.
- Если режим Vault включён, но провайдер экономики недоступен, автомат блокирует запуск и не переходит на золото.

После изменения конфига выполните `/slots reload`. Проверить активный режим и провайдера можно командой `/slots status`.

Удалить ближайшую оставшуюся голограмму AurumSlots можно командой `/slots debug removehologram [радиус]`. Радиус по умолчанию — 8 блоков.

Размер надписи над воронкой задаётся параметром `hologram_scale` (по умолчанию `0.7`). Целые ставки отображаются без лишнего `.0`: например, `10$`, а не `10.0$`.

## Обновление с 1.01

1. Остановите сервер и замените старый JAR на `AurumSlots-1.1.2.jar`.
2. Запустите сервер. Недостающие параметры и сообщения будут добавлены в существующий конфиг автоматически; созданные автоматы сохранятся.
3. Проверьте `use_vault: true`, поскольку версия 1.01 могла сама сохранить здесь `false`.
4. Убедитесь, что установлены Vault и плагин экономики, затем выполните `/slots reload` и `/slots status`.

## Сборка

```text
mvn clean package
```

Готовый JAR появится в `target/AurumSlots-1.1.2.jar`.

## Переименование в AurumSlots

Остановите сервер и удалите старый JAR SimpleSlots из папки plugins, затем установите новый JAR AurumSlots. Одновременная загрузка старого и нового плагинов блокируется.

Если папка `plugins/AurumSlots` ещё не существует, содержимое `plugins/SimpleSlots` автоматически копируется в неё целиком. Исходная папка остаётся резервной копией. Если новая папка уже существует, используется только она: объединения и перезаписи данных нет. Не создавайте пустую новую папку перед первым запуском, если нужен автоимпорт. При ошибке копирования плагин отключается без запуска с пустыми данными.

Команды, права и идентификаторы сохранённых голограмм не изменены. Внутренние Java-пакеты сохранены для совместимости. Пользовательские сообщения в перенесённом конфиге не заменяются автоматически. Версия и игровой функционал при переименовании не менялись.

Команда `/aurumslots` — алиас `/slots`; право `casino.admin` сохранено.
